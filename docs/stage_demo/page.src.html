One program, followed from cells to power

Pick a program and a power window. The placed cells, the switching activity and the per-tile power all follow that choice. Every number comes from the gate outputs: 19 Embench programs and the idle program, each with 20 or more OpenSTA power windows of 1,000 cycles, on the same 76.7 µm core.

STAGE 1 · PLACED CELLS

Which cells this program uses

Each dot is a placed cell, coloured by its mean power over the program's power windows. "Against the suite" shows where this program draws more (red) or less (blue) than the average Embench program.

STAGE 2 · ACTIVITY

When and where it switches

Toggles per 1,000 cycles over the whole run (Verilator, gate level; the axis is zoomed to the program's range). Ticks mark the power windows; click one. The grid shows the 4 × 4 regions at the selected window.

STAGE 3 · POWER

What that costs, tile by tile

OpenSTA per-instance power for the selected window, summed into 16 × 16 tiles. The scale is shared by every program and window, so maps compare directly; default-activity tiles run off this scale (up to about 20× higher).
